# Capturas para el taller

Dejá acá los screenshots de las pantallas que quieras mostrar, con el nombre del
proyecto como nombre de archivo. Después corro `py -3 tools/portadas.py` y las
recorta, las convierte y las pone en la tarjeta.

Nombres que uso:

| Archivo | Proyecto |
|---|---|
| `devatlas.png` | DevAtlas (entra con tu Google y sacale una al catálogo) |
| `figumatch.png` | Figumatch (necesita su base de datos prendida) |
| `flash.png` | Flash |
| `focus.png` | Focus |
| `devdesk.png` | DevDesk |
| `celconnect.png` | CelConnect |
| `chequeo-de-horas.png` | Chequeo de Horas |
| `security-dashboard.png` | Security Dashboard |

Si querés varias de la misma app, numeralas: `flash.png`, `flash-2.png`, `flash-3.png`.
La primera es la portada; el resto van a la galería de la ficha.

No hace falta que sean 16:9 ni de un tamaño exacto: el script recorta lo que sobra.
