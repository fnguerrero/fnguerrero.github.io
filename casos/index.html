01 · .NET + IA

Multimarket

Cuánto sale de verdad una compra, en todas las tiendas a la vez.

  • .NET 10
  • C#
  • SQLite
  • React
  • Vite
  • Claude API

Problema

El precio de vidriera no sirve para decidir: el mismo producto sale distinto al contado que en cuotas, y lo que conviene depende de la inflación y de la tarjeta.

Qué construí

Una API en .NET 10 con SQLite y un front en React. Un único conector VTEX cubre 13 tiendas. Lleva cuotas y promociones a valor presente con la tasa del usuario, y vigila a diario los productos que sigue.

Decisiones

  • La relevancia de los resultados la decide un LLM, con una sola llamada por búsqueda. Las reglas de texto tenían techo y cada categoría nueva pedía otra.
  • El monitoreo diario no usa modelo: comparar precios es aritmética. Así operar sale gratis.
  • Ninguna tienda entra sin comparar su precio contra la página real. Así aparecieron precios de lista inflados 80 veces, productos fantasma y fichas sin stock con precios viejos.

02 · .NET full stack

DevAtlas

Catálogo de aplicaciones de desarrollo: qué hay, dónde está y dónde corre.

  • ASP.NET Core
  • EF Core
  • SQLite
  • React
  • TypeScript
  • Vite

Problema

Con muchos proyectos, recordar el repo, el stack y la URL de cada ambiente termina siendo trabajo de memoria.

Qué construí

Una API REST en ASP.NET Core con EF Core sobre SQLite, con migraciones, y un front en React y TypeScript. Cada aplicación guarda stack, repo, notas, URLs por ambiente (dev, QA y producción) y etiquetas.

Decisiones

  • SQLite: cero infraestructura para una herramienta personal, con EF Core para poder cambiar de motor sin tocar el dominio.
  • Etiquetas como relación muchos a muchos con tabla intermedia, y URLs por ambiente como entidad propia.
  • Cliente de la API tipado en TypeScript, separado de las pantallas.

03 · IA + front

Déficit

Calorías y macros a partir de una foto del plato o de la etiqueta.

  • JavaScript
  • PWA
  • Claude Vision
  • Cloudflare Workers
  • Supabase

Problema

Anotar cada comida a mano es lo que hace abandonar cualquier plan de alimentación.

Qué construí

Una PWA instalable que funciona sin conexión, en JavaScript sin build ni dependencias. Le sacás una foto a la comida y un LLM con visión devuelve calorías y macros.

Decisiones

  • La clave de la API nunca llega al cliente: un Worker de Cloudflare la guarda como secreto y hace de proxy, con límite de 30 pedidos por minuto por IP.
  • Sincronización entre dispositivos con Supabase, protegida con Row Level Security.
  • Núcleo de cálculo puro, en módulos, testeado sin llamar a ninguna API.

04 · IA aplicada

Kit de agentes para desarrollo

Claude Code adaptado al trabajo diario: skills, hooks, subagentes y MCP.

  • Claude Code
  • MCP
  • Hooks
  • Subagentes
  • Python
  • PowerShell

Problema

Probar endpoints, preparar pasajes a producción o revisar seguridad se lleva horas de tareas repetitivas. Y un agente sin estructura rinde poco en trabajos largos.

Qué construí

Más de 25 skills y comandos propios, con hooks y subagentes, conectados por MCP a GitLab, Postman, bases de datos y gestión de tareas. Incluye /nonstop: el agente arma su propia spec y un checklist en archivo, y trabaja horas solo, retomando si el turno se corta. El Visor /nonstop muestra el avance en una sola vista.

Decisiones

  • El estado del trabajo vive en archivos (spec, checklist y bitácora), no en la memoria del modelo. Así sobrevive a los cortes y se puede auditar.
  • Límites explícitos: el agente no pushea, no mergea, no despliega ni escribe en bases sin confirmación.
  • Configuración versionada y sincronizada entre máquinas.
